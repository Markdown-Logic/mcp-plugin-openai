# Public conversion requirements

## Anonymous MCP converter

Use only an actually advertised `convert_markdown` tool. Complete nonempty Markdown is limited to **131,072 UTF-8 bytes**; the streamed JSON-RPC request to **524,288 bytes**; the generated raw file to **2,097,152 bytes**; and the complete JSON response to **3,145,728 bytes**. UTF-8 byte limits differ from character counts. Output is an embedded base64 file, never a stored download. Strict tool arguments reject unknown formats/options, including summary detail. Optional images are at most 16 relative-path entries with PNG/JPEG/GIF data URLs within the envelope budget; no URL-fetch option exists. Existing image decode/pixel budgets still apply.

The MCP converter uses a separate machine native edge prefilter of approximately 20 MCP POST requests/minute per IP per colocation, including discovery and malformed envelopes, before body parsing. HTTP429 includes Retry-After:60. Atomic fleet-wide conversion quotas default to 3 admissions/minute and 20/UTC-day per IP, and 80/UTC-day globally; the global configurable ceiling is 500. Failed admitted renders consume quota and charges are never refunded. Best-effort busy accounting tracks one temporary hold per IP and two globally. Holds expire after 60 seconds without cancelling rendering; expired work may overlap replacement requests, so this is not a strict running-renderer cap. These are source defaults/ceilings, not proof of live configuration. Quota/busy/unavailable/output-limit tool results have `isError: true`. Do not immediately loop, distribute work across identities, or silently shorten the source. Try later, choose another supported format with the full source, or use the browser's larger limits.

The MCP converter has no browser proof requirement. It applies its own edge/admission controls and rejects missing controls or trusted edge provenance. It is independent of private account services. Legacy initialize/Streamable HTTP POST and modern per-request discovery use the same tool; current client skill/file support varies. Ordinary tools/resources/prompts are the fallback. Loading guidance adds no tool or authorization.

Full source is passed to the existing renderer without truncation, and its input hash/byte count is returned. Rendering is not a source archive: source front matter may override supplied presentation options; anonymous clock/format substitutions use UTC/en-US with no project/document/Git identity. Bounded Markdown processing may preserve complex portions as escaped text; unsupported glyphs and image omissions follow the existing engine. PDF/HTML/EPUB can use validated bundled images; DOCX prints image text placeholders. Read the result warnings and disclose these limits before treating a chart-containing DOCX as the requested deliverable.

MCP activity records contain only random ID, time, input byte count, format and status, with IP/country null. Admission stores random daily-salted IP-derived keys. Active-database cleanup removes expired 60-second busy holds on admission or alarms, old daily/minute counters by the next UTC midnight plus one minute, and random salts within two UTC days plus one minute. Idle cleanup depends on platform alarm execution; expiry is accounting only and requires no operator reconciliation. SQLite provider recovery history can retain deleted values for up to 30 days; logs/backups have separate policies, so live deletion is not immediate infrastructure erasure. These abuse keys are pseudonymous, not an anonymity guarantee. No document, filename, output, token or raw IP is persisted by the converter.

## Existing browser converter

The existing `/convert` request is an application/json object. Markdown must be nonempty and at most **1,000,000 decoded UTF-8 bytes**; the streamed JSON body is at most **8,000,000 bytes**, including bundled images and JSON escaping. A client-supplied Content-Length cannot relax either bound. Use the intended format in supported options; the service normalizes options and sanitizes the output filename.

Browser proof, when configured, is supplied through `x-turnstile-token`, not through document text or tool arguments. The public service verifies it before reading conversion input. Headless access is not an exemption. Do not reuse a consumed token blindly or attempt to manufacture proof.

The configured public rate limiter allows 100 requests per 60 seconds per IP with the existing per-colocation semantics. A 429 includes `Retry-After: 60`; do not retry immediately or distribute calls across identities. Do not assert that production challenge configuration is known from source alone.

PDF, HTML, and EPUB can use bundled images and local assets; no URL-fetch option is provided. The current DOCX renderer turns image tokens into text placeholders rather than embedding the bundled images. Disclose that loss before treating a chart-containing DOCX as the requested deliverable. Anonymous substitutions have clock/format context, not project/document/Git identity. The conversion activity record contains metadata, not the document source; this is not a claim about every infrastructure log or an authorization to send sensitive content elsewhere.

Use the website when the client cannot accept the MCP embedded file or needs larger inputs. Browser challenge rules remain specific to `/convert`; machine tool limits do not change that route.
